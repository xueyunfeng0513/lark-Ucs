# Excel 行数机器人：第一阶段

用户已要求直接实现：飞书单聊上传 Excel，先回复收到，再回复总行数。用 Python webhook 沿用 robot_quick_start/python 的事件及消息 API 模式；Codespaces 用于测试。此阶段不转换数据、不连接用友。

行数口径（实现默认）：所有工作表非空行合计，包含表头；全空和仅空白字符的行不算，0/False/公式算有内容，隐藏行和隐藏工作表也计入。回复总数和每张表行数，避免把表尾格式当数据。不执行公式或宏。支持 .xlsx/.xls，至少验证 2000 行。

持久化接收任务后快速 ACK，通知线程先回复收到，再允许计算线程下载解析；最终通知单独重试。事件及消息 ID 去重，通知使用稳定 UUID。下载和文件解析有限额，临时文件自动清理。要求请求验签、校验 token/app_id、仅处理用户单聊。

交付独立示例、自动化测试、启动命令和 Codespaces 配置。没有飞书应用凭证时，用本地 HTTP 替身验证 API 契约，明确尚未进行真实飞书联调。
